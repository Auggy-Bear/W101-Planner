Wizard101 Build Planner

Include sources
An item is kept if any of its sources is ticked, so excluding Card Pack hides pack-only gear but keeps items that also drop or craft.

Priority order - top matters most

Drag a row anywhere in the list, or use the arrows for fine tuning. Top stat outweighs everything below it; untick to ignore it entirely.

Caps - stop valuing a stat past this

Blank = no cap. Power pip is the classic case: past 100% it does nothing, so Best in slot stops chasing it.

Minimums - must-have totals

Hard requirements. Best in slot will sacrifice score to hit these first, then optimise. Leave at 0 to ignore.

Filters

Seasonal detection is name-based (Deckathlete, Yuletide, Hallowe'en, Spooky Carnival, holidays, birthdays, festivals, Midsummer, Autumn) - a heuristic, not a wiki category.
Gems, pins and socket rules
Pins are off by default. Enabling them adds Power/Sword/Shield pins from gear - mainly useful for dual-school builds.
Add the gems you actually own. Circle/Square/Triangle/Tear must match the socket; school "Any" applies everywhere, otherwise the gem only counts for that school's damage, crit, pierce, accuracy or conversion.

Saved settings

School, level, priority order, caps, minimums, sources, locks, exclusions and the equipped build are all remembered and restored when you reopen this page.
